# Organic SEO Toolkit

A local dashboard that helps you earn real organic traffic for any domain.

- **Site audit**: crawls a site and flags missing titles, descriptions, H1s, alt text, thin content, slow pages, robots/sitemap problems.
- **Keyword ideas**: expands a seed into real Google searches (no key needed), long-tail first.
- **Rank tracker**: records your Google position per keyword over time.
- **Content brief**: shows what top-ranking pages cover so you can write something more complete.

## Run it
Runs locally (Node 18+) or on Vercel. Keys and projects are stored in your browser.

```
node server.js
```
Open http://localhost:3000.

Rank tracker and content briefs need a SERP API key. Create a free one at https://serper.dev and paste it under **Settings** (or set `SERPER_API_KEY`).

## How it helps traffic
Audit and fix the problems, target the long-tail keywords, publish pages that cover more than the current top results, and re-check ranks weekly.
